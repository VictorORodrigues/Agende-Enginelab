# Agende-Enginelab
O Agende Enginelab é uma plataforma web desenvolvida para otimizar o fluxo de empréstimos e reservas de equipamentos técnicos no laboratório da Universidade Federal do Ceará (UFC). O sistema garante que recursos valiosos — como GPUs, ESP32s e bibliografias especializadas — sejam utilizados de forma justa e organizada.
